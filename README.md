# ESXX Programmer PCB

This repository contains the KiCad design files for the ESXX Programmer board (previously called ESPM Programmer). This board was originally developed to reprogram the FPGA on the ESPM board inside the PSM and ECM in the dVRK-Si system.

It is now also used to reprogram the FPGA on the ESSJ board inside the PSM and ECM setup joints in a full dVRK-Si system.

This board is connected to the JTAG port on the ESPM or ESSJ via a custom cable. Instructions for making the cable are in `dvrk-s-programmer-cable.pptx`.

The current firmware for this board is in [this repository](https://github.com/jhu-dvrk/esxx-programmer-firmware).  Previous versions (for ESPM Programmer) have been archived [here](https://github.com/jhu-dvrk/espm-programmer-firmware).
